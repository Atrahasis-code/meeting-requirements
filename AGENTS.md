# Community edition

Docker Compose only. English/Spanish UI; Spanish default. Local single-owner installation; SQLite default, PostgreSQL opt-in, one heavy worker. Original transcripts and generated results are immutable; approvals explicit and independent.

ChatGPT application-owned OAuth and Mock only. Never import host credentials or use API key fallback. No subscriptions or calls to a hosted Meeting Requirements service. Model input cannot authorize tools, commands, file edits or delegation.

Use compose.test.yaml with a separate project name. No credentials or models in normal tests. Do not publish or delete data volumes without explicit authorization.
